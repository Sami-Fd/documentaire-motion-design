# Contribuer

Merci de votre intérêt ! / Thanks for your interest!

- **Signaler un problème ou suggérer une idée** : ouvrez une *issue* en décrivant ce que vous avez demandé à Claude, ce qui s'est passé et ce que vous attendiez (une capture d'écran d'une image rendue aide beaucoup).
- **Proposer une correction** : faites un *fork*, modifiez `documentaire-motion-design/SKILL.md`, puis ouvrez une *pull request*.
- **Nouveau style visuel** : ajoutez une entrée dans `STYLES` (`src/theme.ts` dans le Kit) et, si besoin, un filtre dans `DefsPapier` ; décrivez-le dans le tableau des styles.

Avant d'envoyer une PR touchant au code du Kit, vérifiez si possible qu'un projet généré avec le skill passe `npx tsc` et qu'une image fixe se rend (`npx remotion still ...`).

Issues and PRs in English are fine too.
